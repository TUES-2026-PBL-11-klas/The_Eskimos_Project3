# Идея

Платформа за търсене на събития  
Съчетава Култура и Свободно Време,Образование, Спорт, Музика, Литература

# Същност на идеята

Агрегатор на събития   
Уеб платформа, която автоматично събира събития от множество външни източници (публични API-та и сайтове, които поддържат скрейпване), нормализира и сортира данните, и ги представя на потребителите чрез единен, удобен интерфейс с филтри и търсене. 

# Компоненти

Детайлна страница

# Архитектура

микросървис архитектура   
**1.Ingestion**   
Събиране, нормализация, дедупликация и запис на събития в базата.   
**2.API**   
Public REST API, който Next.js frontend-ът консумира. **Read-only** – не пише в базата   
**3\. frontend**

# Техстак

Frontend \- Next.js   
Стилизация \- Tailwind CSS   
Backend \- Python (FastAPI)   
ORM \- SQLAlchemy   
База данни \- PostgreSQL   
Контейнеризация \- Docker \+ Docker Compose   
Оркестрация \- Kubernetes (DOKS)  
CI/CD \- GitHub Actions   
Secrets \- GitHub Secrets \+ Kubernetes Secrets   
Observability \- Prometheus, Discord webhook
